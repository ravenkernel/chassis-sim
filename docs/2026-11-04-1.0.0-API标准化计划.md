# 1.0.0 API 标准化计划（2026-11-04）

## 目标（用户拍板，m02532/m02533）

1. **不留兼容层**，版本号 **1.0.0**（对外声明公共 API 稳定；之后不兼容改动走 2.0.0）。
2. **Python 优先 + YAML 快照**：`EnvConfig` 吸收全部行为参数，提供 `to_yaml()/from_yaml()`，
   保证一次运行可完整复现。观测段与传感器**不**进 YAML DSL，但作为可重建的快照字段序列化。
3. 范围 A–F 全做：统一入口与顶层导出 / 参数收敛与修双家缺陷 / 命名规范化 /
   一键录制回放与 CLI / 工程标准（ruff·mypy·coverage + CI 闸门）/ Protocol 类型化。
4. 删除清单 ①②③④ 全做（见下）；主仓同波迁移。
5. 顶层 API 照草案定稿。

## 模块图（1.0.0）

```
src/chassis_sim/
  __init__.py      公共面，只 re-export 不写实现
  api.py           make() + 三级参数解析（kwargs > cfg > 默认）
  config/          __init__.py（re-export） + schema.py（EnvConfig/RewardConfig） + *.yaml（默认快照）
  obs/             spec.py（段 + ObsSpec） + context.py（原 ObservationBuilder 的 build_context 部分）
  sensors/         specs.py + suite.py
  paths.py         PathExtractor / cartesian_to_polar / np_angle_wrap /
                   segment_is_reverse / gear_is_compliant / GEAR_EPS
  safety.py        SafetyGate
  reward.py        RewardCalculator
  envs/            只留 ChassisSimEnv（+ 内部 privileged/dynamics）
  chassis/ bridges/ controllers/ eval/ render/ planning/ scenarios/
```

删除：`envs/observation.py`（ObsLayout / ObservationBuilder / compute_obs_dims /
BASE_RAW_OBS_DIM）、`envs/config.py`、`envs/path_extractor.py`、`envs/path_utils.py`、
`envs/safety_gate.py`、`envs/reward.py`、`bridges` 里的旧单配置激光接口
（`get_scan` / `scan_to_pointcloud` / `get_lidar_front` / `get_lidar_rear`）与
`env` 上的同款叠加层。`obs.Path` → `obs.PathSegment`。
